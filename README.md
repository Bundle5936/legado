# 本仓库自用版下载

[下载最新版 APK](https://github.com/Bundle5936/legado/releases/latest) · [全部历史版本](https://github.com/Bundle5936/legado/releases) · [查看发布进度](https://github.com/Bundle5936/legado/actions/workflows/TestRelease.yml)

普通安卓手机选择文件名含 `release`、不含 `universal` 的 APK；需要共存版时选择 `releaseA`。沿用此前本仓库测试构建的签名，可直接覆盖对应版本。

推送到 `master` 后自动测试、构建并发布，历史版本保留。也可在 Actions 的 **GitHub APK Release** 中手动运行；无需另配签名或蓝奏账号。每次发布附带 `SHA256SUMS.txt` 校验文件。
